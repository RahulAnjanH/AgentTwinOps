# AgentTwinOps

AgentTwinOps is a documentation-first architecture scaffold for an AI-powered Digital Twin + Multi-Agent DevOps platform.

## Repository intent

This repository currently contains the complete project structure for future implementation.
No business logic, API handlers, authentication flows, or database models have been implemented yet.

## Current structure

- Backend: FastAPI + SQLAlchemy + Alembic + PostgreSQL + Redis + MongoDB
- Frontend: React + TypeScript + Vite + TailwindCSS + React Query
- Shared: cross-cutting contracts and utilities for later use
- Docs: project documentation and architectural references
